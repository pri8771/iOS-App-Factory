# Quality Kit

Trusted deterministic checks, evidence indexes, whole-product experience
coverage, and release certification. Coding agents cannot write its policies or
approve their own evidence.

The first profile is `ios-internal-testflight-v1`. Every public route and state
must be registered under one active design generation, represented in a
critical journey, and backed by deterministic fixture/evidence declarations.
Runtime lineage can then prove that shared components did not reintroduce an
older UI generation.
